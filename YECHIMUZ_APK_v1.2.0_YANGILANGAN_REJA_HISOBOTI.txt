2. ANDROID TEXNOLOGIYALARI TAQQOSLASH HISOBOTI (KOTLIN NATIVE VS CAPACITOR)
================================================================================
Loyiha uchun ikki xil texnologik yo'nalish 8 ta mezon bo'yicha chuqur taqqoslandi:

A) VARIANT A: KOTLIN NATIVE (Jetpack Compose):
   - Ishlash Tezligi: Maksimal yuqori (60-120 FPS), apparat resurslaridan to'liq foydalanish.
   - UI/UX Imkoniyatlari: 100% Native Material 3, zamonaviy imo-ishoralar, haptik qayta aloqa.
   - Backend Integratsiyasi: Retrofit/OkHttp orqali aniq JSON va cookie/header boshqaruvi.
   - Push Notification: FirebaseMessagingService orqali to'liq va cheklovlarsiz boshqaruv.
   - Xavfsizlik: Android Keystore, EncryptedSharedPreferences, R8/ProGuard himoyasi.
   - Kengaytirish: Istalgan native Android SDK, biometrika, sensorlar bemalol ulanadi.
   - Texnik Xizmat: Alohida mobil kod bazasini yuritish talab etiladi.
   - Google Play: 100% tavsiya etilgan format, kichik AAB hajmi, eng yuqori reyting.

B) VARIANT B: CAPACITOR (Web-Native Hybrid Wrapper):
   - Ishlash Tezligi: O'rtacha-yuqori (Android System WebView orqali ishlaydi).
   - UI/UX Imkoniyatlari: Mavjud Next.js UI responsiv ko'rinishida to'g'ridan-to'g'ri aks etadi.
   - Backend Integratsiyasi: Web platformadagi mavjud marshrutlar va cookielar bilan bir zumda ishlaydi.
   - Push Notification: @capacitor/push-notifications plagini orqali ishlaydi.
   - Xavfsizlik: Yaxshi, lekin WebView xavfsizligi va SSL sozlamalari nazorat qilinishi shart.
   - Kengaytirish: Tayyor plaginlarga bog'liq, plagin bo'lmasa native ko'prik (bridge) kerak.
   - Texnik Xizmat: Web UI yangilanganda APK ham tabiiy ravishda oson yangilanadi.
   - Google Play: Mos, lekin ilova "faqat veb oynasi" bo'lib qolmasligi uchun ehtiyotkorlik talab etiladi.

MUHIM QOIDALAR:
Yakuniy texnologiya foydalanuvchi tomonidan yozma tasdiqlanmaguncha "tanlangan"
deb hisoblanmaydi! Qaror to'liq foydalanuvchi ixtiyorida.

3. SINXRONLIK VA REAL-TIME MEXANIZMI ANIQ MEZONLARI
================================================================================
1. MARKAZIY MANBA SINXRONLIGI (SINGLE SOURCE OF TRUTH):
   Web platforma ham, Android ilova ham faqat bitta markaziy Neon PostgreSQL
   ma'lumotlar bazasiga ulanadi. Webda qo'shilgan ma'lumot Androidda bir soniyada
   aks etadi va aksincha.

2. REAL-TIME YANGILANISH TURLARI:
   - Standart so'rovlar (Oddiy API): Ro'yxatdan o'tish, login, muammo yaratish,
     yechim topshirish, profilni ko'rish (Request-Response).
   - Xavfsiz Chat tizimi: Mavjud Web platformadagi kabi 4 soniyalik barqaror
     polling orqali ishlaydi. Vercel Serverless doimiy WebSocket ulanishlarida
     texnik cheklovlarga ega bo'lgani sababli, polling eng barqaror yechimdir.

5. MA'LUMOTLAR BAZASI VA QAT'IY ONLAYN REJIM
================================================================================
- Production Baza: Faqat yagona Neon Tech PostgreSQL.
- Android SQLite: Hozircha tasdiqlanmagan. Foydalanuvchining "Ilova faqat internet
  bor paytda ishlasin, internetsiz kirish bloklansin" talabi sababli, ilovada og'ir
  lokal SQLite bazasi yaratilmaydi.
- Lokal xotira: Faqat Keystore orqali shifrlangan JWT token va sessiya keshini saqlaydi.

6. MAVJUD CHAT TIZIMI INTEGRATSIYASI (v1.1.0)
================================================================================
Web platformaga v1.1.0 da muvaffaqiyatli kiritilgan xavfsiz chat tizimi Androidda
mavjud API orqali qayta yaratilmasdan ishlatiladi:
- GET  /api/v1/chat/[solutionId] -> Xona holati va xabarlar tarixi
- POST /api/v1/chat/[solutionId] -> Yangi xabar yuborish
- GET  /api/v1/chat/my          -> Barcha faol chatlar ro'yxati
- Cheklovlar: Faqat yechim statusi SHORTLISTED, SELECTED, PILOT yoki COMPLETED
  bo'lganda ochiladi. Begona odamlarga 403 Forbidden beriladi.
- 4 soniyalik polling, debounce (takroriy yuborishdan himoya) va CLOSED xona qoidalari.
